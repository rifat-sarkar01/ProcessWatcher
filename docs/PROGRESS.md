## Discoveries (found, not yet planned)
- **ffmpeg 9 can no longer write rotation metadata** (`-metadata:s:v rotate=90` is silently dropped), so a rotated fixture cannot be generated locally. Rotation handling is therefore covered by unit tests on the ffprobe payload (side-data and tag paths) and must be re-checked against a real phone clip once T-1.4 films one.
- Time is always PTS-derived (`frames / nominal_fps` never appears); `TimeMap.is_variable` flags phone VFR input, and normalisation is what makes analysis frames unambiguous.
- **Ruff reads every text file under the repo root, including `docs/*.md`**; a ledger saved in a non-UTF-8 encoding fails `ruff format --check` (happened once in T-0.9 — the ledger is now always written as UTF-8).
- **Abstention is a real DP outcome, not a threshold after the fact:** with weak step probabilities the `none` state can be cheaper than a skip or back transition, so the aligner naturally drops a step instead of forcing it (calibrated abstention, §1A item 4). Tests use strong likelihoods when they intend to exercise skip/back costs.
- The domain guard reuses the aligner's `coverage` (steps with interval and mean P ≥ 0.4 ÷ K) and leaves `domain_cost_max` null until T-3.10 calibrates it, matching `contracts/examples/thresholds.example.json`; with `null` the cost rule is inactive.
- Stitching matches on shared analysis frame indices (polygon IoU at 64x64, box fallback); features rasterise masks the same way with a 2-cell dilation, score contact as `overlap / object area` and bridge hold gaps up to `bridge_s`. Mask-encoding IoU stays with T-2.4/ADR-001.
- Explanations use `mm:ss.cc` timestamps so the ±0.5 s check is exact; the report builder still formats its template as `mm:ss`. Tool detection is a narrow phrase pattern around with/using/used/needs/requires, and the caller passes the procedure vocabulary (tools and parts), so parts such as `bolt` are not misread as unknown tools.
- Evidence items and illustration blocks are optional inputs to the report builder: a deviation with no evidence gets `evidence_unavailable: true` and a deviation with no illustration gets a reason string, so T-3.9 can assemble partial reports before T-4.3/T-4.4 land.
- The illustration watermark is drawn with Pillow's default font (no font files are vendored); the guard lives in `pw.evidence.labeling` and the report builder calls `assert_evidence_kinds` before schema validation.
- Evidence provenance compares a 64-bit dHash with an 8-bit budget rather than bytes: ffmpeg/font builds differ across hosts, so re-renders are never byte-identical. The item still carries exact `output_sha256` for tamper detection of the stored PNG, and verification re-renders from `stages/tracks.json` + `media/analysis.mp4` next to the report.
- The evidence selector takes a `FrameProvider` callable, not a video path: T-4.2/T-3.9 can pass a decoder, tests pass synthetic PIL frames. Missed deviations seed the gap brackets and out-of-order seeds one frame per swapped window before score-filling, so the strategy survives noisy scores; zero usable frames or unreadable frames return `evidence_unavailable` reasons instead of placeholders.
- New npm dependencies (AGENTS.md §4): `react-router-dom`, `axe-core` (dev). `pip-audit` (dev, T-6.5) audits the locked environment. New Python deps: `jsonschema`, `types-jsonschema`, `pymupdf`, `pillow 12.3.0` (T-2.9), `fastapi` + `uvicorn` (T-0.8 runtime), `httpx` (dev, TestClient) — all mature releases inside the 14-day rule.
- **Model APIs (ADR-001/002):** SAM masks are box-local base85 payloads behind a range coder — ask for `metadata.mask_encoding:"one_bit"` (26× smaller), cap groups at 16 objects, expect IDs to survive occlusion while the mask leaks onto the occluder, and treat payloads as opaque (they are not base64). Wonder needs strict `text.format` JSON (20/20 valid), but **temperature 0 is not deterministic** (one scoring step swung 0.08–0.85 over 10 runs), so aggregate with median-of-k (start k=3); video input is sampled (~0.7–0.9k tokens for 20–61 s), reasoning tokens are 93–94% of output, 24 images and 61 s clips are accepted, 4-way parallel shows no 429, and out-of-domain footage is not refused — keep the deterministic coverage guard. The SAM 15,000-frame/file-size ceilings and both models' cost fields stay unverified; the ledger must price frames and tokens itself.
- The `pw` entry point is now `pw.cli:main` (T-0.8) and delegates `overlay`/`verify-evidence`; `pw run` only supports `--mode fake` until T-0.7/T-3.9. Start-up loads `./.env` (or `$PW_ENV_FILE`) through `pw.core.settings`, which fills only unset variables and validates `PW_MODE`, `PW_SPEND_CAP_USD` and the disable switches (live without a key fails loud); `pw config` prints a redacted snapshot and `pw run` takes its default mode from `PW_MODE`. `pw export` (T-5.5) writes HTML and prints PDF with headless Chrome/Edge (`PW_CHROMIUM` override); a missing browser is a typed E-11. The 12-stage fake DAG writes `stages/<stage>.key` = sha256(stage_version ‖ video/sop hashes ‖ dependency artifact hashes ‖ mode), so reruns are no-ops.
- Upload caps come from `04_TRD` §5 (500 MB, 180 s, 3840x2160), not ADR-001 (absent); a "zip bomb" is rejected on container magic and never decompressed, and every cap check runs before ffprobe. Security failures carry `status_code`/`code`/`to_payload()` so T-5.2 can render the `{error:{code,message}}` envelope.
- The audit (`docs/security/audit.md`) closed F-09 (scratch dir now removed when an upload is rejected) and F-10 (pure-ASGI `SecurityHeadersMiddleware`: nosniff, `Referrer-Policy: no-referrer`, CSP — a buffering `BaseHTTPMiddleware` would have broken the SSE stream). F-13 (`pillow` advisories, blocked by `exclude-newer = 2026-10-13`) stays open; the web lockfile is clean after `npm audit fix`.
- Timeline events derive contacts as held-tool ↔ contacted-part (the hand's contact window with the part while the same hand holds the tool), deduped by unordered pair with the earliest sorted hold winning; zones arrive as `Track`s passed via `zones=`, so no SOP import is needed. Debounce merges same-type/same-tracks events, keeping the earliest start, latest end and max confidence.
- The overlay consumes `tracks.json` as-is: `poly` is drawn when present, otherwise the contract-guaranteed `box`, so ADR-001's mask encoding (T-2.4) only changes what the pipeline fills in. `npm run test:perf` measures the overlay's own geometry work on a stub 2D context (jsdom has no canvas); real-browser p95 is verified at T-5.13 e2e. Adding that script is the one edit outside the card's touch list.
- The FE progress view reads SSE with `fetch` + a local frame parser, not `EventSource` (headers cannot be set on `EventSource`, and `/runs/{id}/events` is guarded by `X-Access-Code`); the reducer is idempotent so T-5.4's replay-on-reconnect cannot regress a stage. `02_AppFlow` §2.3 labels the 12th stepper slot "Done", but the DAG has 12 real stages (`deviations` included) and `done` is a run status, so the stepper shows all 12 and completion separately.
- DSH sandbox: ACL/label repair needed once; `pre-commit` cannot bootstrap upstream hooks (gitleaks is a local hook; CI installs the CLI); the web toolchain cannot be sandboxed locally; pytest `tmp_path` and `tempfile` temp dirs are unusable (tests use `.uv/tests-tmp`). Host toolchain: `uv 0.13.6`, `ffmpeg 9.0.2`, `gitleaks 8.30.1` — the redaction fixture in the audit suite is low-entropy on purpose, because gitleaks' `generic-api-key` rule flags realistic-looking keys in tests.
- The deviation panel keeps accept/dismiss/note in local state and calls `onDecide`/`onNote`, because T-5.3's `PATCH /runs/{id}/review` does not exist yet; wiring it is a prop change, not a panel rewrite. `report.notice` is not rendered — the schema has no per-notice severity, so the panel uses the fixed `procedure_not_recognized` copy from 03_UI_Spec §9.
